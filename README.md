### 日结、月结、按量、资源包，先分清这四个词

结算方式和计费模式是两个维度。开通后默认是日结加按量计费，每天 12:00–18:00 结算前一天的用量，先使用、后付费。

日结按当天用量算钱，次日出一张账单；月结先按每天用量计算，次月 1–3 号汇总出账。月结需要联系商务变更，支持带宽计费。资源包则是先买后用，结算时优先从资源包抵扣，超出额度再按量计费。

## 存储怎么收费：0.0048 元/GB/日起，按峰值而不是平均值

标准存储中国境内 0.0048 元/GB/日，中国香港及境外 0.0058 元/GB/日。低频、归档、深度归档依次便宜，但都有最短存储期，提前删除或变更存储类型，仍然按最短期计费。

计费按每天中国境内、中国境外的存储峰值分别计算，每个存储类型单独算，不取平均值。当天某一刻容量冲到最高，就按那个峰值算一整天。

最短存储期是最容易忽略的一笔钱。低频存储必须存满 30 天，归档 90 天，深度归档 180 天，中途删除照样按 30/90/180 天收费。存进去之前先想好这批文件打算放多久：几天内就会删的临时文件，留在标准存储反而最便宜。存 1GB 文件 3 天就删，标准存储花 0.0144 元，低频存储按 30 天收 0.114 元，差了将近 8 倍。

官方给过一个示例：某天中国境内标准存储峰值 100GB，新加坡低频存储峰值 50GB，次日结算 100×0.0048 + 50×0.0048 = 0.72 元。

## 加速服务和其他费用：流量是账单里最不可控的一块

播放加速按产生的下行流量和加速地域计费。具体单价随地域和用量阶梯变化，做预算时以官方价格页的实时价格为准，别拿旧活动的价格表套。

- 媒体分发加速：下行流量 × 对应地域阶梯单价。
- QUIC 下行加速：按 QUIC 请求次数计费。
- 客户端上传加速：按上传加速流量计费，不用不产生。
- 数据取回：低频存储按取回流量计费；归档支持批量、标准、快速三种取回方式，深度归档支持批量、标准取回，都按取回流量收费。
- 图片审核：按审核次数，处理失败不计费。
- 数字水印：按添加或提取水印的视频时长，不足一分钟按一分钟。
- DRM 播放 License：按播放加密视频产生的请求次数。
- 应用管理：20 个及以内免费，超出部分按每日应用峰值数收费。
- 小程序播放器插件 License：预付费，按年收取。
- 短视频 SDK License：购买云点播流量资源包可获赠，也能单独购买。
- 日志服务：按实际投递的日志行数计费。

防盗链功能免费提供，但因流量盗刷产生的费用平台不予退费。部署前把防盗链配好，比事后算账有用。

## 常见问题

### 上传视频到云点播收费吗？

上传动作本身没有单独的计费项，不会因为上传了文件就扣钱。只有使用客户端上传加速功能时，才按上传加速流量收费。

### 转码失败会扣费吗？

不会。媒体处理按成功处理的输出文件计费，处理失败不收取费用，图片审核处理失败同样不计费。

### 把视频删了，存储费就不收了吗？

标准存储的文件删除后不再产生存储费用。低频、归档、深度归档在最短存储期内删除或转成其他类型，仍然按 30/90/180 天计费，这笔钱省不掉。

### 流量被恶意刷了能退费吗？

防盗链免费，但因为流量盗刷产生的费用平台不予退费。上线前把防盗链配好，降低被盗刷的风险。

### 日结和月结怎么选？

默认日结，适合绝大多数中小用量，每天出前一天的账单，用量异常第二天就能发现。月结适合大用量客户，需要联系商务变更，支持带宽计费。

### 为什么账单里的媒体处理时长比实际转码分钟数多？

因为不同规格按抵扣比例换算。H.264 2K 的抵扣比例是 1:8.5，实际转码 100 分钟，计入账单的是 850 分钟媒体处理时长。按 0.016 元/分钟乘回去，才是实际费用。
